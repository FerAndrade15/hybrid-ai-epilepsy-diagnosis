# Hybrid Artificial Intelligence Epilepsy Diagnosis
Herramienta de IA para análisis de señales y diagnóstico médico.
## Virtual Environments
Este proyecto utiliza **dos virtual environments** de Python:

### 1. Virtual Environment - Tensorflow (TF)
```bash
# Activar (Windows)
.\venv\Scripts\activate

# Activar Git Bash
source tf_venv/Scripts/activate

# Desactivar
deactivate
```

### 2. Virtual Environment - PyTorch (PT)
```bash
# Activar (Windows)
.\pt_venv\Scripts\activate

# Activar Git Bash
source pt_venv/Scripts/activate

# Desactivar
deactivate
```

**Nota:** Cada venv contiene sus propias dependencias. Consulta `requirements-all.txt`, `requirements-pt.txt` o `requirements-tf.txt`.
