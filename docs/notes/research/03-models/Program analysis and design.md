# Análisis del programa y diseño en general

## Pipeline
El pipeline completo se considera que debe estar integrado de los siguientes elementos:

Señal cruda
    ↓
Preprocesamiento
    ↓
Extracción de features (o representación)
    ↓
Modelo (ML o DL)
    ↓
Evaluación
    ↓
Interpretación (XAI)
    ↓
Decisión clínica

## Selección y factores relevantes para la arquitectura

1. Densidad de datos
2. Interpretabilidad clínica
3. Recursos computacionales
